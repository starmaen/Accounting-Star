# نجم المحاسبة (Accounting Star)

نظام محاسبي ونقاط بيع عربي متكامل لأندرويد، يعمل **دون إنترنت**، مبني بـ Kotlin + Jetpack Compose + Room.
مصمم للمحاسبين وأصحاب المتاجر والمستودعات، ويصلح لمحلات الألبسة والبقالة ومستحضرات التجميل والمولات.

## المزايا

- **نقاط بيع كاملة**: بيع بالقطعة / نصف الجملة / الجملة، بحث بالاسم والباركود (قارئ باركود يعمل كلوحة مفاتيح).
- **طرق دفع مترابطة**: نقدي، دين (آجل)، وتقسيط مع جدول أقساط شهري وتحصيل تلقائي على الفاتورة.
- **المخزون والمستودعات**: أرصدة لكل مستودع، حد تنبيه، تعديل يدوي، نقل بين المستودعات، حركة مخزون مسجلة لكل عملية.
- **المشتريات والموردون**: فواتير شراء ترفع المخزون تلقائياً وتحدّث مستحقات المورد.
- **العملاء والديون**: رصيد كل عميل، حد ائتمان، رصيد افتتاحي، كشف فواتير، تسجيل دفعات.
- **الفواتير والمرتجعات**: بيع/شراء/مرتجع بيع/مرتجع شراء، خصم وضريبة، حالات السداد.
- **التقارير**: مبيعات اليوم والشهر، الربح الإجمالي، المصروفات، صافي الربح، الأصناف الأكثر مبيعاً، تنبيهات المخزون، ديون العملاء ومستحقات الموردين.
- **الطباعة**: طابعة حرارية بلوتوث 58/80 مم (طباعة صورة تدعم العربية على كل الطابعات) أو طباعة عبر خدمة أندرويد إلى PDF/طابعة شبكة.
- **تعدد المشاريع والفروع**: كل مشروع تجاري معزول ببياناته ومخزونه وعملته وضريبته، مع فروع ومستودعات متعددة.
- **مستخدمون وصلاحيات**: مدير نظام / مدير / كاشير، كلمات مرور مجزأة بملح وتكرار SHA-256.
- **نسخ احتياطي**: تصدير قاعدة البيانات ومشاركتها إلى التخزين أو السحابة.
- **واجهة عربية RTL** وأيقونة تطبيق مخصصة.

## الدخول الأول

```
اسم المستخدم: admin
كلمة المرور:  admin123
```

يُنشئ التطبيق تلقائياً مشروعاً باسم «متجري» وفرعاً رئيسياً ومستودعاً رئيسياً. غيّر بيانات النشاط وكلمة المرور من الإعدادات.

## التثبيت

1. افتح تبويب **Actions** في المستودع.
2. اختر آخر تشغيل ناجح لـ **Android CI**.
3. نزّل الأثر `accounting-star-debug-apk` ثم ثبّت `app-debug.apk` على الجهاز (اسمح بتثبيت التطبيقات من مصادر غير معروفة).

يمكن أيضاً بناء التطبيق محلياً بمتطلبات: JDK 17 و Android SDK 35.

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## بنية المشروع

```
app/src/main/java/com/starmaen/accountingstar/
├── data/          # Room: الكيانات، DAOs، قاعدة البيانات، المستودع، الجلسة
├── domain/        # (محجوز للتوسعة)
├── print/         # مولّد الفاتورة والطباعة الحرارية/PDF
├── ui/            # Compose: ViewModel، الثيم، الشاشات، المكونات
├── util/          # الأموال والتواريخ والتشفير
├── MainActivity.kt
└── AccountingStarApp.kt
```

راجع [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) للتفاصيل التقنية و[docs/USER_GUIDE.md](docs/USER_GUIDE.md) لدليل الاستخدام.

## قاعدة البيانات

Room بإصدار 1، ملف `accounting_star.db`، والكيانات:
`projects, branches, users, warehouses, categories, products, stock, customers, suppliers,
invoices, invoice_items, payments, installments, stock_moves, expenses, transfers`.
