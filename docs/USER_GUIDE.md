# دليل الاستخدام

## 1. الدخول
- اسم المستخدم `admin` وكلمة المرور `admin123` لأول مرة.
- بعد الدخول افتح **الإعدادات** وغيّر اسم النشاط والعملة والضريبة.

## 2. إعداد النشاط
1. **المشاريع**: أنشئ مشروعاً لكل نشاط تجاري مستقل، أو استخدم المشروع الافتراضي.
2. **الإعدادات ← بيانات النشاط**: الاسم، الهاتف، العنوان، العملة، نسبة الضريبة.
3. **الفروع والمستودعات**: أضف الفروع ثم المستودعات، واختر الفرع/المستودع النشط.
4. **المستخدمون**: أضف كاشير أو مديراً، لكل مستخدم كلمة مرور وصلاحية.

## 3. المنتجات
1. افتح **المنتجات** واضغط **+**.
2. أدخل الاسم، الباركود (اختياري)، الوحدة، التكلفة، وسعر القطعة/نصف الجملة/الجملة، وحد التنبيه.
3. أدخل الكمية الافتتاحية عند الإنشاء ليُسجّل المخزون تلقائياً.
4. التصنيفات تُدار من قائمة التصنيف في النموذج.

## 4. العملاء والموردون
- **العملاء**: الاسم، الجوال، النوع (قطعة/جملة)، حد الائتمان، ورصيد افتتاحي إن كان له دين سابق.
- **الموردون**: الاسم والجوال ورصيد افتتاحي إن كان لك مستحق سابق.

## 5. البيع
1. افتح **نقطة البيع** واختر فئة السعر (قطعة/نصف جملة/جملة).
2. ابحث بالاسم أو امسح الباركود ثم اضغط Enter.
3. اضغط **إتمام البيع**:
   - اختر العميل (أو اتركه عميلاً نقدياً).
   - اختر الدفع: نقدي / دين / تقسيط.
   - للدين: أدخل المدفوع الآن (يمكن صفر).
   - للتقسيط: عدد الأقساط الشهرية.
   - أضف خصماً أو نسبة ضريبة.
4. احفظ الفاتورة ثم اطبعها أو أجّل الطباعة.

## 6. الشراء
1. **المشتريات** ← اختر المورد.
2. أضف الأصناف وحدد الكمية وسعر الشراء.
3. أدخل المدفوع للمورد (صفر = آجل بالكامل).
4. عند الحفظ يزيد المخزون ويُحدّث رصيد المورد.

## 7. المخزون
- **المخزون**: اختر المستودع لعرض الأرصدة.
- أيقونة التعديل: أدخل الكمية الفعلية بعد الجرد.
- أيقونة النقل: انقل كمية إلى مستودع آخر.
- تظهر الأصناف الحمراء عند بلوغ حد التنبيه.

## 8. التحصيل والأقساط
- **الأقساط**: تظهر الأقساط المستحقة، اضغط أيقونة الدفع وسجّل المبلغ.
- **الفواتير**: افتح أي فاتورة لرؤية الأصناف والدفعات وجدول الأقساط، وسجّل دفعة أو اطبع.

## 9. التقارير
- اختر الفترة (اليوم / الشهر / تاريخ مخصص).
- راجع المبيعات، المشتريات، الربح، المصروفات، صافي الربح، الأكثر مبيعاً، ونواقص المخزون.
- سجّل المصروفات من زر **مصروف**.

## 10. الطباعة
1. اربط الطابعة الحرارية من إعدادات بلوتوث في الجوال.
2. في **الإعدادات ← الطباعة** أدخل عنوان MAC واختر 58/80 مم.
3. امنح إذن البلوتوث عند طلب الاختبار.
4. بدون MAC ستُطبع عبر خدمة أندرويد (PDF/شبكة).

## 11. النسخ الاحتياطي
- **الإعدادات ← النسخ الاحتياطي** ينشئ نسخة من قاعدة البيانات ويشاركها.
- احفظها في Google Drive أو أي تخزين خارجي دورياً.

## 12. نصائح
- أنشئ مشروعاً منفصلاً لكل نشاط بدل خلط البيانات.
- استخدم نصف الجملة/الجملة للعملاء التجاريين، والقطعة للأفراد.
- راجع تقرير «أصناف تحت حد التنبيه» أسبوعياً.
- لا تحذف التطبيق قبل أخذ نسخة احتياطية.
