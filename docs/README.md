## ملخص سريع

تطبيق أندرويد محاسبي عربي يعمل دون إنترنت، مبني بـ Kotlin وJetpack Compose وRoom.
يدعم البيع بالقطعة ونصف الجملة والجملة، الدفع النقدي والدين والتقسيط، المخزون متعدد
المستودعات، المشتريات، الموردين، العملاء، الفواتير والمرتجعات، التقارير، الطباعة
الحرارية، والنسخ الاحتياطي. يمكن تقسيمه إلى مشاريع تجارية منفصلة تماماً لكل منها
فروعها ومستودعاتها وعملتها وضريبتها.
